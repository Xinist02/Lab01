# Lab01



Описание задачи:

Программа вычисляет высоту центра тяжести усеченной трехгранной пирамиды от нижнего основания. Площади оснований рассчитываются по формуле Герона на основе длин сторон. Итоговый результат конвертируется и выводится в метрах.



Порядок ввода:

Программа ожидает ввод 7 вещественных чисел через пробел или перенос строки строго в следующем порядке:



Длины сторон нижнего основания: a1, b1, c1 (в сантиметрах).

Длины сторон верхнего основания: a2, b2, c2 (в сантиметрах).

Высота пирамиды: h (в сантиметрах).



Никакого дополнительного текста в консоль не выводится, программа сразу ждет ввода данных.



Запуск программы:

Откройте проект Lab01 в Visual Studio. Соберите решение через меню Build → Build Solution (или Ctrl+Shift+B). Запустите программу без отладки через меню Debug → Start Without Debugging (или Ctrl+F5). В появившемся окне консоли введите необходимые 7 чисел и нажмите Enter для получения ответа.
